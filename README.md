# Review Builds and Hosted Betas

## Golden Day Club

The mobile lending beta is hosted from `golden-day-club/` and includes administrator, lender, and delegated-manager workflows, adjustable interest and fees, duration-based due dates, repayments, a ledger, and portfolio analytics.

**Data warning:** the hosted beta stores its data in the current browser. It is for interface and workflow testing only until the production Supabase database and authentication are activated.

## CommonRoom review builds

Android staging packages remain distributed through GitHub Releases. They are internal review builds and are not production releases.
